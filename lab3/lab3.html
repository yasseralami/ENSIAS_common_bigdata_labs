from pyspark.sql.window import Window

w_rang  = Window.partitionBy("client_id").orderBy(F.desc("amount"))
w_cumul = Window.partitionBy("client_id").orderBy("ts")

(tx.withColumn("rang", F.row_number().over(w_rang))

from pyspark.sql.window import Window

w = Window.partitionBy("colis_id").orderBy("ts")

(scans.withColumn("ordre", F.row_number().over(w))

      .withColumn("attente_h", (F.unix_timestamp("ts") - F.unix_timestamp("scan_precedent")) / 3600)

w_rang  = Window.partitionBy("magasin").orderBy(F.desc("montant"))

3. Une requête en deux étapes (CTE)

Databricks · SQL
%sql
WITH par_client AS (
  SELECT client_id, SUM(amount) AS total
  FROM tx
  GROUP BY client_id
)
SELECT c.segment, COUNT(*) AS nb_clients, ROUND(AVG(p.total), 2) AS total_moyen
FROM par_client p
JOIN clients c ON p.client_id = c.client_id
GROUP BY c.segment
Databricks · SQL
%sql
WITH bornes AS (
  SELECT colis_id,
         MIN(CASE WHEN etape = 'PRISE_EN_CHARGE' THEN ts END) AS debut,
         MAX(CASE WHEN etape = 'LIVRE' THEN ts END)           AS fin
  FROM scans
  GROUP BY colis_id
)
SELECT b.colis_id, c.transporteur, c.promesse_h,
       (unix_timestamp(b.fin) - unix_timestamp(b.debut)) / 3600 AS delai_h
FROM bornes b
JOIN colis c ON b.colis_id = c.colis_id
WHERE b.fin IS NOT NULL
Databricks · SQL
%sql
WITH par_magasin AS (
  SELECT magasin, SUM(montant) AS ca
  FROM ventes
  GROUP BY magasin
)
SELECT m.region, COUNT(*) AS nb_magasins, ROUND(SUM(p.ca), 2) AS ca_region
FROM par_magasin p
JOIN magasins m ON p.magasin = m.magasin
GROUP BY m.region

En cas de problème
  • NameError (par exemple name 'tx' is not defined) : une cellule précédente n'a pas été exécutée dans cette session. Réexécutez les cellules depuis la section 1.
  • TABLE_OR_VIEW_NOT_FOUND : exécutez la cellule USE CATALOG workspace / USE SCHEMA lab3 (section 0) ou les vues temporaires (section 4).
  • PATH_NOT_FOUND : le fichier n'est pas dans le volume raw ou son nom diffère.
  • Une colonne entièrement null après lecture : le schéma ou une option de lecture (sep, timestampFormat) ne correspond pas au fichier.
  • AMBIGUOUS_REFERENCE après une jointure : préfixez la colonne par son DataFrame ou joignez sur le nom de colonne ("client_id") plutôt que sur une expression.
