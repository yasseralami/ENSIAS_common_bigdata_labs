Démarrer le cluster dans Codespaces

  1. Sur la page du dépôt : Code → Codespaces → Create codespace on main (ou rouvrez votre Codespace existant).
  2. Dans le terminal du Codespace, mettez le dépôt à jour et démarrez les conteneurs :
    git pull
docker compose up -d
  3. Ouvrez un terminal dans le conteneur maître :
    docker exec -it cluster-master bash
  4. Ouvrez les interfaces web depuis l'onglet Ports : 9870 (HDFS), 8088 (YARN), 4040 et 4041 (Spark UI), 8081 (Kafka UI).
  5. En fin de séance : docker compose stop, puis arrêtez le Codespace sur github.com/codespaces.

Ne modifiez pas docker-compose.yml : quand un lab a besoin d'un outil en plus, son énoncé indique comment l'installer. Préférez stop à down, qui supprime les conteneurs et ce que vous y avez installé.

Choisir sa filière

Rendre son travail

  • À la fin de chaque lab, cliquez sur « Envoyer à l'enseignant », avant la date limite annoncée.
  • Gardez une copie avec « Télécharger une copie » ; si l'envoi échoue, transmettez ce fichier à l'enseignant.
  • Rédigez vous-même les réponses de réflexion : l'IA générative est autorisée comme assistant en lab, pas pour écrire vos réponses.

Dépannage

ProblèmeSolution
ssh: connect to host hadoop-slave1 port 22: Connection timed outLe pare-feu du Codespace bloque le réseau des conteneurs : suivez le guide de correction.
Live datanodes (0) ou un seul DataNodeMême correction, puis stop-all.sh et start-all.sh dans cluster-master.
Le Spark UI ne s'ouvre pasVérifiez que l'application tourne encore, puis ouvrez le port 4040 (ou 4041) dans l'onglet Ports.
Kafka UI ne montre aucun topicVérifiez que Kafka tourne (jps dans cluster-master) et ouvrez le port 8081, pas 8080.
TABLE_OR_VIEW_NOT_FOUND sur DatabricksRéexécutez la cellule USE CATALOG / USE SCHEMA de la section 0 du lab.
Connexion refusée par MongoDB AtlasDans Network Access, ajoutez l'adresse demandée par le lab, puis vérifiez la chaîne de connexion.
Le bouton d'envoi échoueTéléchargez la copie de vos réponses et transmettez-la à l'enseignant.
