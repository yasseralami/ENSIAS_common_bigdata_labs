GitHub Codespaces vous donne une machine Linux dans le navigateur, avec VS Code, un terminal et Docker. Le cluster Hadoop tourne dans trois conteneurs Docker sur cette machine.

1. Créer votre Codespace

  1. Ouvrez le dépôt du cours sur GitHub (lien donné par l'enseignant).

  3. Attendez la fin de la préparation : la première fois, comptez 3 à 5 minutes (décompression des données et téléchargement des images Docker).
Votre quota Codespaces gratuit est limité. Arrêtez toujours votre Codespace en fin de séance (dernière section). Activez le GitHub Student Developer Pack pour disposer de plus d'heures.

Question de validation

Quel processus stocke physiquement les blocs de données sur un nœud ?

Répondez à la question de validation pour débloquer ce bouton.

Le dossier assets/ du dépôt est monté dans le maître sous /shared_volume. Il contient purchases.txt (plus de 200 Mo d'achats dans une chaîne de magasins) et alice.txt (le livre Alice au pays des merveilles).

Dans HDFS, un chemin qui ne commence pas par / est relatif à votre répertoire personnel /user/root.

1. Créer l'arborescence

cluster-master
hdfs dfs -mkdir -p /user/root
hdfs dfs -mkdir -p input web_input
hdfs dfs -ls
Deux dossiers : /user/root/input et /user/root/web_input.

2. Copier les fichiers de la machine locale vers HDFS

cluster-master
hdfs dfs -put /shared_volume/purchases.txt input/
hdfs dfs -copyFromLocal /shared_volume/alice.txt web_input/
hdfs dfs -ls -R -h
La copie de purchases.txt prend quelques secondes. Dans la liste, le chiffre affiché juste après les droits est le facteur de réplication.

3. Lire un fichier

cluster-master
hdfs dfs -cat input/purchases.txt | head -5
hdfs dfs -tail web_input/alice.txt
N'utilisez jamais -cat seul sur un fichier de 200 Mo : il afficherait des millions de lignes. Ajoutez toujours | head. Si cela arrive, appuyez sur Ctrl + C.

4. Droits, copies, déplacements

cluster-master
# Observer puis modifier les droits
hdfs dfs -ls web_input
hdfs dfs -chmod go-r web_input/alice.txt
hdfs dfs -ls web_input

# Copier dans HDFS, déplacer la copie, puis la supprimer
hdfs dfs -cp web_input/alice.txt alice_copie.txt
hdfs dfs -mkdir archive
hdfs dfs -mv alice_copie.txt archive/
hdfs dfs -ls -R archive
hdfs dfs -rm -r archive

5. Récupérer un fichier de HDFS vers la machine locale

cluster-master
hdfs dfs -get web_input/alice.txt /shared_volume/alice_copie.txt
hdfs dfs -du -h
Le fichier alice_copie.txt apparaît dans le dossier assets/ de l'explorateur de fichiers du Codespace.
Question de validation

Dans le résultat de hdfs dfs -ls, que signifie le chiffre affiché juste après les droits d'un fichier ?

Répondez à la question de validation pour débloquer ce bouton.

HDFS découpe chaque fichier en blocs de taille fixe, puis copie chaque bloc sur plusieurs DataNodes. Observons-le sur purchases.txt.

cluster-master
# Paramètres du cluster : taille de bloc (en octets) et facteur de réplication
hdfs getconf -confKey dfs.blocksize
hdfs getconf -confKey dfs.replication

# Taille exacte du fichier, puis ses blocs et leur emplacement
hdfs dfs -du input/purchases.txt
hdfs fsck /user/root/input/purchases.txt -files -blocks -locations
Chaque ligne commençant par un numéro (0., 1., …) décrit un bloc : sa taille (len=) et la liste des DataNodes qui en stockent une copie.

Vérifiez aussi dans l'interface HDFS : Utilities → Browse the file system → user → root → input, cliquez sur purchases.txt et parcourez les onglets Block 0, Block 1…

Question de validation

Un fichier de 300 Mo est stocké avec des blocs de 128 Mo et un facteur de réplication de 3. Combien de copies de blocs sont stockées dans le cluster ?

Répondez à la question de validation pour débloquer ce bouton.

Gardez l'interface YARN (port 8088) ouverte : chaque job y apparaît comme une application, avec son état et sa progression.

1. Calcul de π (démonstration du parallélisme)

Hadoop estime π par une méthode de Monte-Carlo : il tire des points au hasard, répartis entre plusieurs tâches map. Le premier paramètre est le nombre de maps, le second le nombre de points par map.

cluster-master
hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.2.0.jar pi 2 1000
hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.2.0.jar pi 10 10000
La dernière ligne affiche Estimated value of Pi is …. Relevez les deux valeurs.

2. WordCount Java, le « Hello World » de MapReduce

cluster-master
hadoop jar /shared_volume/wordcountJob.jar /user/root/web_input/alice.txt /user/root/output/wordcount_java
À la fin, repérez dans les compteurs affichés les lignes Launched map tasks et Launched reduce tasks.

Affichez les 10 mots les plus fréquents :

cluster-master
hdfs dfs -ls output/wordcount_java
hdfs dfs -cat output/wordcount_java/part-r-00000 | sort -k2 -nr | head -10

Relancez maintenant exactement la même commande hadoop jar /shared_volume/wordcountJob.jar … et observez ce qui se passe.

Question de validation

Dans un WordCount, que fait la phase reduce ?

Répondez à la question de validation pour débloquer ce bouton.

Hadoop Streaming permet d'écrire le mapper et le reducer dans n'importe quel langage : chaque script lit des lignes sur l'entrée standard et écrit des paires clé<TAB>valeur sur la sortie standard. Ouvrez assets/mapper.py et assets/reducer.py dans l'explorateur du Codespace et lisez-les.

1. Simuler MapReduce sans Hadoop

Avec de simples « tuyaux » Linux, on reproduit les trois phases sur les 50 premières lignes du livre :

cluster-master
cd /shared_volume

# Phase map seule
head -50 alice.txt | python3 mapper.py | head -8

# Map, puis tri (le rôle du shuffle), puis reduce
head -50 alice.txt | python3 mapper.py | sort | python3 reducer.py | head -8

# Même chose SANS le tri : comparez
head -50 alice.txt | python3 mapper.py | python3 reducer.py | head -8

cd ~

2. Exécuter le même code sur le cluster

cluster-master
hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-3.2.0.jar \
  -files /shared_volume/mapper.py,/shared_volume/reducer.py \
  -mapper "python3 mapper.py" \
  -reducer "python3 reducer.py" \
  -input /user/root/web_input/alice.txt \
  -output /user/root/output/wordcount_python
cluster-master
hdfs dfs -cat output/wordcount_python/part-00000 | sort -k2 -nr | head -10
Le classement doit être identique à celui du WordCount Java : même algorithme, autre langage.
Question de validation

Pourquoi le reducer Python peut-il additionner les valeurs « tant que la clé ne change pas » ?

Répondez à la question de validation pour débloquer ce bouton.

Chaque ligne de purchases.txt contient 6 champs séparés par des tabulations :

[0] date [1] heure [2] magasin [3] catégorie [4] montant [5] paiement
2012-01-01 09:00 San Jose Men's Clothing 214.05 Amex

Objectif : calculer le total des ventes de chaque magasin. Le reducer est fourni (assets/ventes/reducer_ventes.py). À vous de compléter les deux lignes marquées TODO dans assets/ventes/mapper_ventes.py, en ouvrant le fichier dans l'éditeur du Codespace.

1. Tester localement sur 1 000 lignes

cluster-master
cd /shared_volume/ventes
head -1000 /shared_volume/purchases.txt | python3 mapper_ventes.py | head -5
head -1000 /shared_volume/purchases.txt | python3 mapper_ventes.py | sort | python3 reducer_ventes.py | head -5
cd ~
Le mapper doit afficher des lignes du type San Jose 214.05. S'il affiche None None, les deux lignes TODO ne sont pas encore complétées.

2. Lancer le job sur le cluster, sur le fichier complet

cluster-master
hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-3.2.0.jar \
  -files /shared_volume/ventes/mapper_ventes.py,/shared_volume/ventes/reducer_ventes.py \
  -mapper "python3 mapper_ventes.py" \
  -reducer "python3 reducer_ventes.py" \
  -input /user/root/input/purchases.txt \
  -output /user/root/output/ventes_magasin

Pendant l'exécution, suivez l'application dans l'interface YARN, et relevez à la fin les compteurs Launched map tasks et Launched reduce tasks. Puis affichez les 5 magasins qui vendent le plus :

cluster-master
hdfs dfs -cat output/ventes_magasin/part-00000 | sort -t$'\t' -k2 -nr | head -5
Vous devez relancer le job après une correction ? Supprimez d'abord la sortie précédente : hdfs dfs -rm -r output/ventes_magasin.

Question de validation

Quelle limite de MapReduce, observée aujourd'hui, Spark cherche-t-il à lever (TP de la semaine 3) ?

Répondez à la question de validation pour débloquer ce bouton.

Les commandes hdfs dfs s'appuient sur une API Java, la classe FileSystem, que les applications utilisent pour lire et écrire dans HDFS. L'application hadoop-hdfs-app.jar fournie en montre quatre opérations. Syntaxe : hadoop jar hadoop-hdfs-app.jar <opération> <dossier> <fichier>.

Opération Méthode Java utilisée Effet
status getFileStatus(path) taille, propriétaire, droits, réplication
info getFileBlockLocations(...) emplacement de chaque bloc
read open(path) lecture du début du fichier
write create(path) création d'un fichier
cluster-master
hadoop jar /shared_volume/hadoop-hdfs-app.jar status /user/root/web_input alice.txt
hadoop jar /shared_volume/hadoop-hdfs-app.jar info /user/root/input purchases.txt
hadoop jar /shared_volume/hadoop-hdfs-app.jar read /user/root/web_input alice.txt
hadoop jar /shared_volume/hadoop-hdfs-app.jar write /user/root hello.txt
hdfs dfs -cat hello.txt
Comparez la sortie de info avec celle de hdfs fsck (section 3) : ce sont les mêmes informations, obtenues par programme.

En cas de problème
  • `.': No such file or directory : le répertoire personnel n'existe pas. Lancez hdfs dfs -mkdir -p /user/root.
  • Name node is in safe mode : HDFS vient de démarrer et vérifie ses blocs. Attendez 30 secondes et réessayez.
  • Output directory … already exists : supprimez le dossier de sortie avec hdfs dfs -rm -r <dossier>.
  • docker: command not found : vous êtes dans le terminal du maître. Utilisez le terminal Codespace.
  • hdfs: command not found : vous êtes dans le terminal Codespace. Entrez dans le maître avec docker exec -it cluster-master bash.
  • Un port n'apparaît pas dans l'onglet Ports : vérifiez avec jps que le service tourne, puis ajoutez le port à la main.
